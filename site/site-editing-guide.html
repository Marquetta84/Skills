Editing Your Website — Plain-English Guide

For Prominent Roofing Co. · keep this page open in one tab while you edit in another

1. How to open a file to edit

  1. Log into Hostinger → File Manager
  2. Open public_html
  3. Right-click the file you want (e.g. index.html) → Edit
  4. This opens a code editor in your browser. It looks technical, but you only need to touch the plain English sentences — leave anything inside <...> alone.
  5. Use Ctrl+F (Windows) or Cmd+F (Mac) inside the editor to search for text, so you don't have to scroll and hunt.
  6. Make your change, then click Save in the editor. Refresh your website in a new tab to see it live.
Before you edit anything: download a fresh backup zip from File Manager (select everything in public_html → Compress) before making changes. If something breaks, you can re-upload the backup and start over. Never delete a < or > symbol — those hold the page together.

3. Common edits

Change the phone number

Search for 857-5181 in each of the 4 files. It appears 2–3 times per file (desktop menu, mobile menu, footer). Change the number in two places each time it appears:

  • The text you see, e.g. (901) 857-5181
  • The hidden tappable link just before it, e.g. tel:19018575181 — same digits, no spaces or symbols, with a leading 1

Change the email address

Search for info@prominentroofing.shop in each file — same idea, it appears in the text and inside a mailto: link right before it.

Change headlines / paragraphs / button text

All the sentences on the site are in plain English inside the code — search for a few words from the sentence you want to change (Ctrl+F) and type your replacement between the same > and < symbols. Example: to change the Home page headline, search Memphis's Most Trusted Roofing Experts in index.html.

Change the 6 services on the Services page

In services.html, search SERVICE BLOCK — you'll find 6 labeled sections (Replacement, Repair, Storm Claims, Inspections, Gutters, Commercial). Each one has its own heading, paragraph, and 3-item checklist you can edit independently.

Change a photo

Easiest method: keep the exact same file name. In File Manager, go to the images folder, delete the old photo, and upload your new photo using the exact same file name (e.g. your new hero photo must also be named hero-roof-install.jpg). The website will pick it up automatically — no code editing needed.

If you want to use a different file name, you'll need to also update the matching src="images/...jpg" line in the HTML file.

Change the colors

Open css/style.css — the first ~25 lines are labeled EDIT ME: SITE-WIDE COLORS. Each line is one color used across the whole site (main red, dark text, backgrounds, etc). Change the 6-character code (like #E31B23) and it updates everywhere at once. Search "hex color picker" online to find new codes.

Change business hours / service area

Search Mon–Sat: 7am (Contact and footer) and Germantown, Cordova, Bartlett (Contact page) to update these.

5. If something looks broken

The most common cause is an accidentally deleted <, >, or " symbol near where you edited. Undo your last edit (or re-upload your backup zip), and try again — just change the plain-English words, nothing else.
